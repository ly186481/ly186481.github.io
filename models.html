생존분석 (Kaplan–Meier, Cox)

“얼마나 오래 걸리는가, 그리고 무엇이 그 속도를 바꾸는가”

내 석사 논문으로 보는 상세 해설 — 실업 기간과 정신건강 연구를 단계별로 풀어 쓴 페이지입니다. 논문 기반 해설 보기 →

이 모델이 묻는 것

실업 기간, 고객 이탈까지의 시간처럼 사건이 일어날 때까지의 시간을 다룹니다. 평균만 보면 아직 사건이 안 일어난 사람(중도절단)을 버리게 되는데, 생존분석은 이들을 “지금까지는 버텼다”는 정보로 활용합니다.

핵심 개념
생존함수 S(t): t 시점까지 사건이 안 일어났을 확률
위험함수 h(t): t 시점까지 버틴 사람이 바로 그다음 순간 사건을 겪을 위험

돌리는 순서

  1. 데이터를 기간(time), 사건 여부(event: 1=발생, 0=중도절단), 설명변수로 정리
  2. Kaplan–Meier로 집단별 생존곡선을 먼저 그려 모양 확인 (S(t)=∏(1−dᵢ/nᵢ))
  3. Log-rank 검정으로 집단 차이 확인
  4. Cox 비례위험모형으로 변수를 통제한 효과 추정: h(t|x)=h₀(t)·exp(βx)
  5. 비례위험 가정 점검 후 해석
library(survival)
km  <- survfit(Surv(dur, event) ~ group, data = df)
plot(km); survdiff(Surv(dur, event) ~ group, data = df)

cox <- coxph(Surv(dur, event) ~ mh + age + edu, data = df)
summary(cox)     # exp(coef) = 위험비(HR)
cox.zph(cox)     # 비례위험 가정 검정

읽는 법

HR > 1그 변수가 클수록 사건 위험이 높다 (사건이 더 빨리 일어남)
HR < 1사건 위험이 낮다 (사건이 늦게 일어남)
HR = 1.30다른 조건이 같을 때 위험이 약 30% 높다
신뢰구간1을 포함하면 통계적으로 구분하기 어렵다
가장 흔한 실수 — 무슨 사건을 정의했는지를 먼저 확인하세요. 사건이 “실업 탈출(취업)”이면 HR>1은 좋은 신호(빨리 탈출)이고, 사건이 “이탈”이면 HR>1은 나쁜 신호입니다. 또 HR은 인과가 아니라 연관입니다.

패널회귀 (고정효과)

“같은 대상을 시간에 따라 관찰하면, 눈에 안 보이는 차이를 걷어낼 수 있다”

이 모델이 묻는 것

은행, 국가, 기업처럼 같은 개체를 여러 시점에 관찰한 데이터에서 변수 사이의 관계를 봅니다. 단면 회귀와 달리 개체마다 고유한 성격(경영 문화, 지역 특성 등 관측되지 않는 요인)을 통제할 수 있습니다.

돌리는 순서

  1. 개체×시점 형태(long format)로 데이터를 정리하고 결측·불균형 확인
  2. Pooled OLS, 고정효과(FE), 확률효과(RE)를 각각 추정
  3. Hausman 검정으로 FE와 RE 중 선택
  4. 개체 단위 군집 표준오차로 추론 (개체 수가 적으면 주의)
library(plm); library(lmtest)
fe <- plm(y ~ x1 + x2, data = pdata, model = "within")
re <- plm(y ~ x1 + x2, data = pdata, model = "random")
phtest(fe, re)                              # Hausman
coeftest(fe, vcov = vcovHC(fe, cluster = "group"))

읽는 법

  • 계수는 “개체 내 변화”의 효과입니다. x1이 1 늘어난 같은 은행의 y가 평균 β만큼 변한다고 읽습니다. 은행 간 비교가 아닙니다.
  • 시간에 변하지 않는 변수(설립 연도 등)는 FE에서 식별되지 않아 사라집니다.
  • Hausman 검정에서 p값이 작으면 RE 가정이 깨졌다는 뜻이므로 FE를 씁니다.
  • 표준오차는 반드시 군집 보정을 확인하세요. 이것만 달라져도 유의성이 바뀝니다.
주의 — FE는 “고정된 차이”만 통제합니다. 시간에 따라 변하면서 y와 x에 동시에 영향을 주는 요인(역인과, 동시 충격)은 남아 있어 인과 해석에는 추가 근거가 필요합니다.

VAR (벡터자기회귀)

“한 변수에 충격이 오면 다른 변수는 언제, 얼마나 반응하는가”

이 모델이 묻는 것

금리, 환율, 물가, 수출처럼 서로 영향을 주고받는 변수들을 모두 내생변수로 놓고, 각 변수를 모든 변수의 과거값으로 설명합니다. 계수 자체보다 충격반응함수(IRF)와 분산분해(FEVD)로 읽는 모형입니다.

돌리는 순서

  1. 각 변수의 단위근 검정(ADF)으로 정상성 확인, 필요하면 차분이나 로그차분
  2. 정보기준(AIC/BIC)으로 시차 선택
  3. VAR 추정 후 안정성(특성근 절댓값이 1 미만) 확인
  4. 그레인저 인과, IRF, FEVD 계산
library(vars)
VARselect(dat, lag.max = 8, type = "const")
m   <- VAR(dat, p = 2, type = "const")
roots(m)                                     # < 1 이어야 안정
causality(m, cause = "rate")                 # 그레인저
ir  <- irf(m, impulse = "rate", response = "gdp", n.ahead = 12, boot = TRUE)
plot(ir)
fevd(m, n.ahead = 12)

읽는 법

IRF한 변수에 표준편차 1만큼 충격을 줬을 때 다른 변수가 시간에 따라 어떻게 움직이는지. 신뢰구간이 0을 포함하는 구간은 반응이 있다고 말하기 어렵다.
FEVD예측오차 변동 중 각 충격이 설명하는 비중. 정책 충격이 얼마나 중요한지 가늠
그레인저 인과X의 과거값이 Y의 예측에 추가 정보를 주는가. 진짜 인과가 아니라 선행성
개별 계수변수 간 다중공선성 때문에 직접 해석하지 않는 게 일반적
주의 — Cholesky 분해를 쓰면 변수 순서가 결과에 영향을 줍니다. 앞에 놓은 변수는 같은 시점에 뒤 변수에 영향을 주지만 반대는 아니라고 가정하기 때문입니다. 순서를 바꿔 결과가 유지되는지 확인하세요.

연관규칙 (Apriori)

“A를 가진 사람은 B도 함께 가지는가”

이 모델이 묻는 것

장바구니 분석에서 시작된 방법으로, 항목들이 우연보다 자주 같이 나타나는 조합을 찾습니다. 예측 모델이 아니라 패턴 탐색 도구입니다.

세 가지 지표

지지도 (support)전체 중 A와 B가 함께 나타난 비율
신뢰도 (confidence)A가 있는 경우 중 B도 있는 비율
향상도 (lift)신뢰도 ÷ B의 전체 비율. 1보다 크면 우연보다 자주 함께 나타남

직접 계산해 보기

돌리는 순서

library(arules); library(arulesViz)
trans <- as(split(df$item, df$id), "transactions")
rules <- apriori(trans, parameter = list(supp = 0.01, conf = 0.5, minlen = 2))
rules <- sort(rules, by = "lift", decreasing = TRUE)
inspect(head(rules, 10))
plot(rules, method = "graph")

읽는 법

  • 신뢰도만 보면 속습니다. B가 원래 너무 흔하면 어떤 A에서도 신뢰도가 높게 나오므로 향상도를 함께 보세요.
  • 지지도가 너무 낮은 규칙은 우연일 가능성이 큽니다. 최소 지지도를 현실적으로 설정하세요.
  • 규칙 방향(A→B)은 인과가 아니라 동시 출현의 방향일 뿐입니다.
