Credit Card Fraud Detection: Predictive Models

카드 사기 탐지는 “정확도 99.8%”가 아무 의미 없는 문제입니다. 극단적으로 불균형한 데이터에서 모델을 고르고, 평가하고, 경보 기준을 정하는 과정을 단계별로 풀어 썼습니다.

1. 문제 정의

카드 승인 요청이 들어오면 몇 백 밀리초 안에 승인, 차단, 추가 인증 중 하나를 정해야 합니다. 모델은 거래마다 사기 확률 점수를 내고, 점수가 기준선을 넘으면 경보를 울립니다. 점수가 애매한 거래는 사후 조사 대기열의 우선순위에도 쓰입니다.

목표: 사기는 최대한 잡되, 정상 고객이 결제 거절을 겪는 일은 최소로.
이 둘은 서로 맞바꾸는 관계라서, 모델 점수와 별개로 경보 기준 설계가 핵심입니다.

2. 왜 어려운가

극단적 불균형대표적 공개 데이터인 ULB 신용카드 데이터는 거래 284,807건 중 사기가 492건(약 0.17%)입니다.
정확도의 함정전부 정상이라고 답해도 정확도 99.8%입니다. 정확도로는 모델의 가치를 알 수 없습니다.
사기범의 적응수법이 바뀌어 과거 패턴이 낡습니다(컨셉 드리프트).
라벨 지연사기 확정은 고객 이의 제기를 거쳐 몇 주 뒤에 됩니다. 최근 데이터일수록 사기가 덜 표시되어 있습니다.

3. 데이터와 특징

원시 거래(금액, 시각, 가맹점, 지역)만으로는 약하고, 카드별 과거 행동과 비교한 변수가 성능을 좌우합니다.

  • 빈도: 최근 10분·1시간·24시간 거래 횟수
  • 금액: 평소 결제액 대비 비율, 직전 거래 대비 증가폭
  • 맥락: 해외 결제, 신규 가맹점, 심야, 온라인·오프라인 전환
  • 이동: 직전 거래와의 거리와 시간 간격(물리적으로 불가능한 이동)
주의 — 특징은 해당 거래 시점까지의 정보로만 만들어야 합니다. 미래 정보가 섞이면 검증 성능이 부풀려지는 데이터 누수가 됩니다.

4. 자주 쓰는 모델

로지스틱 회귀기준선 모델. 계수로 설명이 가능해 고객 문의와 감독 대응에 유리
랜덤포레스트·그래디언트부스팅XGBoost, LightGBM 등. 정형 거래 데이터에서 비선형 관계와 변수 간 상호작용을 잘 잡아 실무 주력
이상탐지Isolation Forest, 오토인코더. 라벨이 적거나 새로운 유형을 찾을 때 보조로 사용
룰 엔진모델과 병행. 특정 가맹점 차단처럼 즉시 대응이 필요한 경우

보통 로지스틱 회귀를 기준선으로 두고, 부스팅 모델이 얼마나 더 나은지 비교한 뒤 비용 대비 효과로 선택합니다.

5. 불균형 처리

  • 클래스 가중치: 사기 거래의 오류에 더 큰 벌점을 줍니다. 가장 단순하고 안전한 출발점입니다.
  • 언더샘플링: 정상 거래를 일부만 사용해 학습합니다. 정보 손실이 있습니다.
  • SMOTE(합성 과표집): 사기 거래와 비슷한 가상 샘플을 만들어 늘립니다.
흔한 실수 — 샘플링을 데이터 분할 전에 적용하면 검증 데이터에 학습 정보가 새어 들어갑니다. 분할한 뒤 학습 데이터에만 적용하고, 검증·테스트 데이터는 실제 분포(불균형) 그대로 둡니다.

6. 평가

탐지율 (Recall)실제 사기 중 잡아낸 비율
적중률 (Precision)경보를 울린 거래 중 진짜 사기의 비율
PR-AUC재현율-정밀도 곡선 아래 면적. 불균형 데이터에서는 ROC-AUC보다 개선 폭이 잘 드러납니다.
검증 방식과거로 학습하고 이후 기간으로 검증하는 시간 순서 분할. 무작위 분할은 같은 카드의 거래가 양쪽에 섞여 성능이 부풀려집니다.

8. 운영과 한계

  • 드리프트 관리: 정기적 재학습, 점수 분포와 탐지율 모니터링
  • 설명 가능성: 고객이 거절 사유를 물으면 답할 수 있는 사유 코드 제공
  • 사람과의 협업: 모델이 조사 대기열의 순서를 정하고, 확정은 조사 인력이 합니다.
  • 데이터 한계: 공개 데이터는 변수가 익명화되어 있어 특징 설계 연습에는 한계가 있습니다.
학습·정보 제공 목적의 해설입니다. 계산기의 수치는 설명을 위한 가정입니다.
